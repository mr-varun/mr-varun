## 🏦 What I Work On at Sookth

> Company products — source code is private.

<table width="100%">
<tr>
<td width="50%" valign="top">

### 🏛️ Mark 2 — Cooperative Banking SaaS
Multi-tenant banking platform for cooperative banks.

- FD / RD / SB deposits, loans, pigmy collection
- Inter-Branch Transactions with double-entry accounting
- SMS alerts with TRAI DLT-compliant templates
- Role tiers: Super Admin → Bank Admin → Staff

`PHP 8` `MySQL` `MVC` `Bootstrap 5`

</td>
<td width="50%" valign="top">

### 📱 Sookth Mobile Pigmy
Field-agent collection app that syncs a bank's local MS Access database with a remote MySQL server.

- Pigmy collection workflows
- Two-way sync between branch and cloud
- [Live on Google Play](https://play.google.com/store/apps/details?id=com.sookthmobilepigmy.app)

`Python` `Flask` `MySQL` `MS Access`
